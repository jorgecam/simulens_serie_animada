# SimuLENS — Prioridad de fuentes · v4 plana

Cuando haya contradicciones:

1. Decisión explícita más reciente del usuario.
2. Canon maestro: `00_...` a `05_...`.
3. Skills activas: `skill_*.md`.
4. Documento del episodio: `video_*.md`.
5. Biblioteca operativa: `runway_prompts.md`.
6. Histórico: `archive_runway_raw.txt`.

Reglas:
- Las skills depuradas tienen más autoridad que prompts históricos.
- `archive_...` nunca es fuente de verdad.
- El asset visual aprobado más reciente prevalece sobre descripción textual antigua.
- Fondo limpio > reconstrucción desde una imagen con personajes.
- Character sheet > descripción improvisada.
- `apertura.mp4` y `cierre.mp4` son fijos y no se regeneran.
