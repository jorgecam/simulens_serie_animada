# SimuLENS — Localizaciones y assets

## 1. Principio

Escenarios, maquinaria y objetos recurrentes se tratan como assets visuales autoritativos.

## 2. Laboratorio

### Escenario base
La variante **básica** es la que no tiene escritorio delante.
Es la referencia principal cuando no hace falta un puesto específico.

### Variantes
Existen variantes con puestos/mesas para:
- ordenador;
- inspección / radioscopio;
- trabajo manual;
- otros encuadres recurrentes.

Las variantes derivan del mismo espacio y no deben rediseñar el fondo.

### Orden de maquinaria

Cuando las tres máquinas principales aparezcan juntas, de izquierda a derecha:

> **torno → bloqueadora → pulidora**

No mezclar formas entre equipos.
Cada máquina debe respetar su asset específico.

### Otros elementos recurrentes

- radioscopio;
- bandejas de chucks/tacos;
- herramientas de precisión;
- viales y consumibles;
- mesas;
- teclado / monitor;
- cuadro o diseño de lente;
- reloj;
- estantería/manuales cuando corresponda.

## 3. Clínica

Escenario cálido y humano:
- teal;
- madera;
- plantas;
- equipo de optometría;
- iluminación suave.

Emma es el personaje clínico por defecto.
Carl/Mia aparecen como pacientes o familia.

## 4. Pantallas

Preparar como assets separados cuando la precisión importe.
No inventar textos clínicos o interfaces complejas.
