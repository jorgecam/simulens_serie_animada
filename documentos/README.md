# SimuLENS — estructura plana v4

Todos los archivos activos están en una única carpeta.

Prefijos:
- `00_...`–`05_...` → canon maestro.
- `skill_...` → instrucciones reutilizables.
- `video_...` → documentación específica de episodios.
- `runway_...` → material operativo.
- `archive_...` → histórico, nunca fuente de verdad.
- `apertura.mp4` / `cierre.mp4` → vídeos fijos.

Para ChatGPT Project, el conjunto recomendado es todo excepto `archive_runway_raw.txt`
si se quiere minimizar al máximo el ruido de recuperación.

No se necesitan subcarpetas, manifest ni changelog.
